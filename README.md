## README — Blossom and Rosebud Bakery 

### Overview
This project contains a simple **HTML-only** website for **Blossom and Rosebud Bakery**. It demonstrates basic website structure, **multi-page navigation**, and **HTML forms**

### Pages Included
1. **index.html** — Home  
2. **about.html** — About Us  
3. **products.html** — Products  
4. **enquiry.html** — Enquiry (includes an enquiry form using HTML inputs)  
5. **contact.html** — Contact (includes contact details and a contact form)

### Navigation
Each page contains the same navigation bar using relative links:
- Home → `index.html`
- About Us → `about.html`
- Products → `products.html`
- Enquiry → `enquiry.html`
- Contact → `contact.html`

### Forms
#### Enquiry Form (`enquiry.html`)
Includes fields such as:
- Full name
- Email address
- Telephone number
- Enquiry type (dropdown)
- Preferred date (date input)
- Quantity (number input)
- Message (textarea)

#### Contact Form (`contact.html`)
Includes fields such as:
- Name
- Email
- Message

> Note: Since this is an **HTML-only** project, the forms are not connected to a backend and do not submit to a server (they are for demonstration).

### Technologies Used
- **HTML only**
